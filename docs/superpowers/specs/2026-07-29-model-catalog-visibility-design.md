# 模型广场全量可见设计

## 目标

模型广场向登录用户和未登录访客展示完整的可用模型目录、模型支持的全部分组及价格。用户即使没有某个分组的调用权限，也可以查看该分组和对应价格；真实 API 调用权限、渠道选择和计费逻辑保持不变。

本功能仅在本地开发和验收，不部署到当前生产服务器。

## 当前问题

`GET /api/pricing` 当前在后端按 `GetUserUsableGroups` 做两次裁剪：

- 删除只存在于用户不可用分组的模型。
- 从 `group_ratio` 删除用户不可用分组。

前端因此拿不到完整模型、分组和价格，无法通过单纯的页面调整解决。

## 已确认规则

- 展示至少在一个启用渠道中可用、且模型元数据未停用的全部模型。
- 不展示仅存在于停用渠道、停用模型或无可用渠道中的条目。
- 登录用户看到其当前用户分组到目标分组的实际倍率，包括分组间特殊倍率。
- 未登录访客看到完整目录和全局基础倍率价格。
- 登录用户无权使用的分组显示锁图标和“不可用”，但仍可筛选、查看模型及价格。
- 未登录访客不在每个分组重复显示锁，只作为公开目录浏览。
- 实际调用权限不因广场展示而改变。

## 后端响应设计

扩展现有 `GET /api/pricing`，不新增重复的 catalog 接口：

- `data`: 返回完整定价缓存，不再调用 `filterPricingByUsableGroups`。
- `group_ratio`: 返回所有展示分组的倍率。登录用户使用 `GetGroupGroupRatio` 覆盖后的实际倍率，未登录使用基础倍率。
- `usable_group`: 保持现有语义，只表示当前登录用户真实可调用的分组。
- `all_group`: 新增字段，返回完整展示分组及说明。
- `vendors`、`supported_endpoint`、`auto_groups` 和版本字段保持现有契约。

`all_group` 从以下集合取并集：

- 全局分组倍率配置中的分组。
- 完整定价数据 `enable_groups` 中出现的显式分组。

没有单独说明的分组使用分组键作为展示名。`enable_groups` 包含 `all` 时，前端按 `all_group` 展开其可展示分组，不把 `all` 当作用户可选择的真实分组名称。

公开响应仍只包含现有模型定价、供应商展示信息、分组和端点描述，不返回渠道 ID、上游地址、密钥或管理配置。

## 前端展示

- 分组筛选来源改为 `all_group`，不再只从当前可见模型或 `usable_group` 推断。
- 登录用户的分组可用状态由 `usable_group` 判断。
- 锁定分组使用锁图标、不可用状态和工具提示，但仍可被选择。
- 选择具体分组后，卡片、表格和详情按该分组的实际倍率计算价格。
- “全部分组”视图展示该模型所有支持分组中的最低价格。
- 若最低价格来自锁定分组，价格旁同步显示锁图标；不得把它表现成当前可直接调用的价格。
- 模型详情的分组价格表完整展示所有支持分组、倍率、价格和可用状态。
- 搜索、供应商、标签、计费类型和端点筛选继续在完整目录上工作。

动态或分层计费模型继续使用现有表达式解析和价格计算函数，只改变传入的分组倍率和可见分组集合，不复制计费算法。

## 权限边界

- `/api/pricing` 只负责目录展示。
- Relay 请求中的用户分组检查、目标分组可用性、渠道选择和最终扣费保持原实现。
- 前端锁图标不是安全边界，后端不得根据广场返回值放宽调用。
- `usable_group` 保持原语义，避免其他页面误把全部展示分组当成授权分组。

## 缓存与性能

- 继续复用 `model.GetPricing()` 的全局定价缓存。
- 每个请求只进行内存中的分组倍率覆盖、集合构建和响应组装，不增加数据库逐模型查询。
- 不建立第二份全量目录缓存，避免定价刷新后两个接口不同步。
- 前端 React Query 缓存键保持不变；用户登录状态变化时必须使 pricing 查询失效或包含身份维度，避免匿名基础倍率残留到登录视图。

## 测试与验收

- 未登录响应包含完整模型和基础倍率。
- 普通用户响应包含仅存在于不可用分组的模型。
- 特殊分组间倍率正确覆盖目标分组价格。
- `usable_group` 不包含无权分组，`all_group` 包含完整展示集合。
- `all` 模型正确展开，不产生名为 `all` 的筛选项。
- 停用模型和仅停用渠道模型不出现。
- 具体分组筛选、锁状态和详情价格一致。
- “全部分组”最低价来自锁定分组时明确显示锁。
- 登录和退出后定价缓存不会串用身份倍率。
- 调用权限回归测试证明无权用户仍然不能使用锁定分组。
- 桌面和手机布局无文本溢出或控件重叠。
