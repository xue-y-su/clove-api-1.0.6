# 邀请海报导出设计

## 目标

把当前“下载二维码画布”升级为可直接分享的完整邀请海报。海报使用信息框版式，包含站点品牌、邀请文案、真实二维码、邀请码和域名，并允许用户在下载前选择尺寸及是否展示昵称。

本功能需要适用于使用该源码部署的其他站点，不硬编码 Clove API 品牌。

## 已确认规则

- 采用已确认的 B 信息框海报版式。
- 自动读取当前站点名称和 Logo。
- 管理员可以设置邀请海报标题和副标题。
- 标题留空时默认使用 `邀请你加入「{站点名称}」`。
- 副标题留空时默认使用 `扫码注册，邀请码将自动填写`。
- 下载前提供“显示我的昵称”开关，首次默认开启。
- 昵称使用 `display_name`，为空时回退到用户名，永不使用邮箱。
- 昵称作为独立的“来自 {昵称} 的邀请”文案，不改写管理员自定义标题。
- 输出尺寸可选：
  - `4:5`：`1080 × 1350`
  - `3:4`：`1080 × 1440`
  - `9:16`：`1080 × 1920`
- 首次默认 `3:4`，之后记住用户上一次尺寸和昵称开关选择。
- 下载内容是完整 PNG 海报，不是单独二维码。
- 默认前端和 Classic 前端保持一致。

## 系统设置

新增两个站点级设置：

- `InvitationPosterTitle`
- `InvitationPosterSubtitle`

约束：

- 标题最大 80 个 Unicode 字符。
- 副标题最大 160 个 Unicode 字符。
- 标题支持 `{站点名称}` 占位符。
- 空值不持久化默认文案，由渲染层按当前语言和站点名称生成默认值。
- 自定义文本作为纯文本渲染，不解释 HTML。

设置放在现有注册相关系统设置区域，通过既有设置读写接口保存。用户二维码弹窗从现有系统配置和邀请数据取得渲染参数，不新增服务端图片生成接口。

## 海报内容与版式

海报从上到下包含：

1. 站点 Logo 和站点名称。
2. `INVITATION` 状态标识。
3. 深色细边信息框。
4. 可选的“来自 {昵称} 的邀请”短句。
5. 管理员标题或默认标题。
6. 管理员副标题或默认副标题。
7. 高纠错等级的真实注册链接二维码。
8. 完整邀请码明文，供无法扫码时手动输入。
9. 当前站点域名和“专属邀请”页脚。

三种尺寸复用同一视觉语言，但不是简单拉伸：`9:16` 将二维码和文字改为纵向布局，`4:5` 和 `3:4` 使用紧凑的左右二维码信息区。所有尺寸保持二维码正方形和足够静区。

标题、副标题、昵称和站点名按固定宽度自动换行。超过可容纳行数时使用省略号，不通过视口宽度缩放字体，也不允许文字覆盖二维码或页脚。

## 前端交互

现有二维码弹窗调整为：

- 缩放后的实时海报预览。
- `4:5 / 3:4 / 9:16` 分段尺寸选择。
- “显示我的昵称”开关，首次开启。
- 带下载图标的“下载 PNG”命令按钮。

尺寸与昵称偏好使用带版本的 localStorage 键保存，不写入用户数据库。切换设置时只重绘预览，不重新请求或改变邀请码。

下载文件名经过非法字符清理，格式为：

```text
{站点名称}-invitation-{邀请码}.png
```

## 渲染与可靠性

使用离屏 Canvas 按目标像素尺寸绘制，不截取缩放后的 DOM。渲染输入是一个明确的数据对象：站点名称、Logo、标题、副标题、昵称、邀请码、注册链接和尺寸。

- 复用现有 `qrcode.react` 生成的真实二维码画布，并按整数像素缩放到导出 Canvas。
- Logo 为同源或允许跨域读取时绘制图片。
- 外部 Logo 不允许 Canvas 读取、加载失败或超时时，使用站点名称文字标识继续导出。
- 在调用下载前等待字体、Logo 和二维码准备完成。
- `toBlob('image/png')` 返回空值或抛错时显示明确错误，不触发空文件下载。
- 导出逻辑与弹窗组件分离为可直接测试的纯渲染模块；默认和 Classic 主题复用同一渲染规则，避免两份海报漂移。

## 国际化与无障碍

- 默认标题、副标题、控制标签、按钮和错误消息使用现有 i18n。
- 管理员自定义文案按原文显示，不自动翻译。
- 尺寸控制使用可键盘操作的分段控件，昵称使用开关。
- 预览图提供描述性替代文本；下载按钮在渲染中显示禁用和忙碌状态。

## 测试与验收

- 系统设置的空值默认、占位符替换、长度校验和纯文本处理。
- `display_name`、用户名回退和昵称关闭状态。
- 三种导出尺寸的 Canvas 像素宽高完全匹配规格。
- 标题、副标题、长昵称和长站点名不会覆盖二维码或页脚。
- 自定义标题不被昵称改写。
- 同源 Logo 正常绘制，跨域失败时文字品牌回退。
- 导出 PNG 非空，具有有效 PNG 文件头和非空像素。
- 从导出的 PNG 实际解码二维码，结果等于带邀请码的注册链接。
- localStorage 初始默认和上次选择恢复正确。
- 默认前端和 Classic 前端的入口、控件和下载行为一致。
- 使用 Playwright 检查桌面和手机弹窗，确认预览无裁切、溢出或重叠。
