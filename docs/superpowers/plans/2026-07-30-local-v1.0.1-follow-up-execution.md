# Clove API V1.0.1 Local Follow-Up Execution Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Execute the approved billing/channel, model-catalog, invitation-poster, subscription-redemption, and rc22 companion plans into one tested local `Clove API v1.0.1-beta` source delivery.

**Architecture:** Work in dependency order but parallelize disjoint files. Land durable backend contracts before UI, keep every feature behind its documented default/config behavior, and use focused TDD commits. The final gate rebuilds one local QA container against the preserved database volume, proves both frontends and browser workflows, then archives only committed Git content.

**Tech Stack:** Go, React/TypeScript, Classic React/JavaScript, Bun, Playwright, Docker, MySQL/Redis, Git archive.

---

## Dependency Order

1. Subscription purchase counter, unified redemption endpoint, and audit labels are independent and first.
2. Tool snapshot, Meter, atomic funding, and finalizer precede Alpha Search and Sub2API.
3. Sub2API publication records precede the catalog plan's Sub2API gate; catalog core projection may run earlier.
4. Poster designer and independent rc22 companion fixes may run alongside backend work when files do not overlap.
5. Default/Classic integration follows each backend contract; Snow remains untouched.
6. Full verification, local runtime rebuild, final commit, and source archive happen only after every focused plan is green.
